 Внешняя сортировка - Документация
1. Требования к окружению

- Python 3.8 или выше (программа протестирована на Python 3.14)
- Операционная система: Windows / Linux / macOS


2. Быстрый запуск

2.1. Убедитесь, что Python установлен

   python --version

   Если Python не установлен, загрузите его с сайта: https://www.python.org/downloads/

2.2. Перейдите в директорию проекта

   cd D:\作业\研究生\python

2.3. Запустите программу (без ограничения памяти, рекомендуется)

   python "multiway merge.py" random_numbers.txt

2.4. С указанием ограничения памяти (опционально)

   python "multiway merge.py" random_numbers.txt 50000000

   Параметр M означает максимальное количество целых чисел, загружаемых в память.
   Каждое число занимает 4 байта. Использование памяти ≈ M × 4 байта.

   Значения M:
   - 10,000,000  → ~40 МБ   → обычный ПК
   - 50,000,000  → ~200 МБ  → рекомендуется
   - 100,000,000 → ~400 МБ  → большой объем памяти
   - 500,000,000 → ~2 ГБ    → сервер


3. Формат входного файла

Файл random_numbers.txt является текстовым файлом, каждое целое число на новой строке.
Пример содержания:

725369949
2596888732
1858565274
1898950332
2065513564

Программа поддерживает:
- Одно число на строку
- Числа, разделенные пробелами или переводами строк
- Пустые строки автоматически пропускаются


4. Выходной результат

Программа создает в той же директории файл random_numbers_sorted.bin,
содержащий все целые числа в порядке возрастания.
(Бинарный формат, 32-битные беззнаковые целые, порядок little-endian)


5. Пример выполнения

$ python "multiway merge.py" random_numbers.txt

Не указан M, используется значение по умолчанию: 1000000000000 (без ограничения памяти)

6. Проверка результата сортировки

Просмотр первых 20 чисел (наименьшие):

python -c "import struct; f=open('random_numbers_sorted.bin','rb'); nums=[struct.unpack('<I',f.read(4))[0] for _ in range(20)]; print('Первые 20:', nums)"

Просмотр последних 20 чисел (наибольшие):

python -c "import struct; f=open('random_numbers_sorted.bin','rb'); f.seek(-80,2); nums=[struct.unpack('<I',f.read(4))[0] for _ in range(20)]; print('Последние 20:', nums)"


7. Алгоритм работы

Этап 1: Сортировка блоков
1. Исходный файл разбивается на блоки по M целых чисел
2. Каждый блок загружается в память и сортируется (быстрая сортировка)
3. Отсортированные блоки записываются во временные файлы
4. Все блоки обрабатываются параллельно через пул процессов

Этап 2: Многопутевое слияние
1. Одновременно открываются несколько отсортированных временных файлов
2. Используется куча (приоритетная очередь) для выбора текущего минимального числа
3. Выбранное число записывается в выходной файл
4. Процесс повторяется многоуровнево, пока не останется один файл
5. Слияние также выполняется параллельно

Анализ сложности:
- Временная сложность: O(n log n)
- Пространственная сложность: O(M + K), где M — лимит памяти, K — количество путей слияния
